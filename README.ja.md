# ChatGPT Outline Community — 長いChatGPT会話の目次を表示

ChatGPTの会話にクリック可能な目次を追加する、ソース公開型の軽量Chrome拡張機能です。

![ChatGPT Outline community demo](./jump-ezgif.com-crop.gif)

**[Chrome ウェブストアで Outlinesave を入手](https://chromewebstore.google.com/detail/opbngifmlnoahbhjhgmngkggedlofddj)** · **[HTMLエクスポートのデモを見る](https://wisteriasoftware.uk/demo)**

> **注意：** コミュニティ版で移動できるのは最初の15項目のみです。以下のOutlinesave機能は別製品の正式版に含まれます。

## 会話の目次が必要な理由

長い会話では以前の質問や回答を探しにくくなります。目次から必要な箇所へ移動できます。

## コミュニティ版の機能

- ChatGPT会話のクリック可能な目次
- 会話の更新に合わせて目次を更新
- サイドバーの左右切り替え
- デモ版の制限：移動できるのは最初の15項目のみ

## より多機能な Outlinesave

Outlinesave は ChatGPT、Gemini、Claude、DeepSeek の会話をナビゲート、検索、注釈、エクスポートできる拡張機能です。

### 2階層の目次とタイトル検索

質問を第1階層、AI回答の見出しを第2階層に表示。目次のタイトルを検索して移動できます。ChatGPTの400ターン以上の会話でもテストしていますが、読み込みには時間がかかる場合があります。

### 邪魔にならない操作

サイドバーの展開・折りたたみ・非表示、小さなフローティング操作部、サイズや位置の調整に対応。対応画面ではJ/Kで移動、Escで閉じられます。操作はAIサービスごとに異なります。

### オフラインで読めるレスポンシブHTML

会話を単一のHTMLファイルとして保存し、PCやスマートフォンでオフライン閲覧できます。目次、全文検索、ブックマーク、ハイライト色フィルター、メモ、コード、数式、Mermaid図を保持します。

**[HTMLエクスポートのデモを見る](https://wisteriasoftware.uk/demo)**

### ハイライト、メモ、ブックマーク

4色のハイライト、下線、メモ、ブックマーク、フィルターに対応。MarkdownとJSON形式でも保存できます。

### ローカル優先・Outlinesaveアカウント不要

会話本文は原則ブラウザ内で処理され、Outlinesaveのサーバーへ送信されません。製品アカウントは不要です。ストア版には最小限の匿名動作イベントがあり、任意の外部接続はユーザー操作で開始します。

### Google Driveへの手動バックアップ

必要なときに自分のGoogle DriveへMarkdownを保存できます。自動同期ではありません。

### Inbox Localと連携した知識管理

Inbox Localは別のローカル優先ワークスペースです。MarkdownやリッチHTMLを取り込み、フォルダー、タグ、全文検索、閲覧、注釈、手動バックアップを利用できます。

[Inbox Local](https://github.com/sunny314woo/wisteria-suite/tree/main/apps/inbox-local)

## コミュニティ版と正式版の比較

| 機能 | コミュニティ | Outlinesave |
|---|---|---|
| ChatGPTの目次 | 最初の15項目 | 対応 |
| 2階層目次と検索 | なし | 対応 |
| ハイライト・メモ・ブックマーク | なし | 対応 |
| HTML / Markdown / JSON | なし | 対応 |
| Gemini・Claude・DeepSeek | なし | 対応 |

## よくある質問

### ChatGPTに目次を追加するには？

コミュニティ版のデモ、または正式版Outlinesaveを利用してください。

### 長い会話を検索できますか？

正式版では目次タイトル検索、エクスポートしたHTMLでは全文検索ができます。

### 単一のHTMLでオフライン保存できますか？

はい。目次、検索、色フィルター、メモを保持します。

### アカウントは必要ですか？

Outlinesaveアカウントは不要です。Google Driveへの保存は手動で行います。

## コミュニティ版のローカルインストール

chrome://extensions でデベロッパーモードを有効にし、このフォルダーをパッケージ化されていない拡張機能として読み込みます。
